## Rules
1. Memory makes searching faster; it never replaces searching.
2. If memory conflicts with the latest search result → trust the latest result and fix the memory.
3. Every entry must include a date (YYYY-MM-DD).
4. Never store passwords, card details, email addresses, or personal data unrelated to the task.
5. Keep `search-log.md` to the 50 most recent entries — remove the oldest when it exceeds that.
6. Status values in memory use the same three values as CLAUDE.md: `มี` / `ไม่มี` / `ไม่พบข้อมูล`.
